# Git contributions and AI disclosure

## Collaboration evidence

- The PDF assesses genuine individual Git contributions across the assignment
  timeline: meaningful commits/messages, contribution graphs and clear task ownership.
- Do not fabricate authorship, contributions, history, screenshots or results.
  Do not rewrite history to manufacture participation.
- Agent-initiated commits, pushes, publication and portal submission require an
  explicit user request or existing authorization for that action. Implementation
  or local packaging alone does not authorize them.
- Do not assign another team member's identity to agent work or infer identities
  from an unrelated reference project.

## AI declaration

- The report must name AI tools used and include the exact prompts.
- Analysis, understanding, idea generation and instruction-resource work are AI
  assistance, as is generated code. Do not claim no AI was used for this work.
- Preserve exact user prompts when recording authorized evidence; do not substitute
  a summary for the report's exact-prompt requirement.
- No BLUEVERSE logging paths, team mapping or reflection requirements apply here.
  Use this assignment's report requirements; do not create unsolicited member logs.
- Do not include secrets or hidden model reasoning in evidence.
